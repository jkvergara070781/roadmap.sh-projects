## Accessible Form UI

https://roadmap.sh/projects/accessible-form-ui

Overview:

In this project, I created a form UI using only HTML and CSS. The form included fields for a full name, email, password, and check box input along with a button to toggle the visibility of the password text. Additionally, the form featured a completeness progress bar and a checklist of requirements that must be met for the form to reach 100% completeness. The goal of this project is not only help practice HTML and CSS but also focus on creating an accessible form that is easy to use for all users, including those with disabilities.
