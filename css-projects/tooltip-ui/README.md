## Tooltip UI

https://roadmap.sh/projects/tooltip-ui

Overview:

In this project, I created a tooltip that appears above navigation items when hovered using only HTML and CSS. The project focuses on mastering CSS positioning, hover effects and creating visually appealing tooltips with relying on JavaScrip. The goal of this project is to understand how to use CSS for dynamic UI effect. Learn how to position elements relative to each other, create smooth transistions and make navigation more interactive and user-friendly.
