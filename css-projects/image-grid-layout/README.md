## Image Grid Layout

https://roadmap.sh/projects/image-grid

Overview:

In this project, I created a grid layout using HTML and CSS. I arranged six images in a grid pattern. The primary focus of this project was to practice the CSS layout technique. 

Key objectives of this project:

- **Grid Structure**: Understand the fundamental of CSS grid, including grid containers, rows, columns, and how to place items within the grid.
- **Responsive Design**: Learn to make the grid layout responsive so that it adapts to different screen sizes.
- **Alignment and Spacing**: Explore to align grid items and manage spacing between them to achieved a clean and visually appealing layout.
