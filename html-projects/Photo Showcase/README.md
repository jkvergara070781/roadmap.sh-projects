## Photo Showcase

https://roadmap.sh/projects/photo-showcase

Overview: 

In this project, I build a single HTML page that showcases a small collection of photos and video.

Key requirements implemented in this project:

- **A semantic page**: Used `<header>`, `<main>`, and `<footer>` to structure the page.
- **At least six images** inside the main content. Each `<img>` include:
    - A `src` that points to a real image.
    - A useful `alt` attribute that describes the image.
    - `width` and `heigth` attributes to reserve layout space and prevent the page from jumping.
- **Captions images** using `<figure>` and `figcaption`.
- **One decorative image** with `alt=""` so screen reader skip it.
- **One embedded** `<video>` with `controls`, a `poster` image.
- **Head metadata**: Set `<title>`, `<meta charset>`, `<meta viewport>`.
