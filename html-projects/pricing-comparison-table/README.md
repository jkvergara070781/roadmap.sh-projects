## Pricing Comparison Table

https://roadmap.sh/projects/pricing-comparison-table

Overview:

In this project, I created s single HTML page that compares three subscription plan side by side using HTML table. 

Key requirements implemented in this project:

- **A semantic page**: Use **<header>**, **<main>**, and **<footer>** to structure the page.
- A real **<table>** with **<thead>** and **<body>** separating header rows from data rows.
- A **<caption>** as the first child of the table that names what is being compared.
- **Header space**: Use **scope="col"** on column headers, and **scope="row" on the plan-name cells so screen readers can announce data in context.
- **A merged cell**: Add a **rowspan**.
- **Head metadata**: Set **<title>**, **<meta charset>**, and **<meta viewport>**.
