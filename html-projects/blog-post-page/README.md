## Blog Post Page

https://roadmap.sh/projects/blog-post-page

Overview: 

In this project, I build a single HTML page that represents one blog post.

Key requirements implemented in this project:

- **Page regions**: Used `<header>` for the site name and primary navigation, `<main>` containing single `<article>` for the post itself, and `<footer>` for closing content like copyright.
- **One** `<h1>` for teh post title. Used `<h2>` and `<h3>` for sub-sections inside the article.
- **Real text elements**: Used `<p>` for paragraphs, `<ul>` for list, `<blockquote>` with `<cite>` for the source for quoted text, and `<code>` and `<pre>` for inline code and code block.
- **Emphasis with meaning**: Used `<em>` for stress and `<strong>` for importance.
- **Descriptive link text** on every link.
- **One image inside the article** wrapped in `<figure>` with a `<figcaption>`. Set useful `alt` on the `<img>`.
- **Head metadata**: Set `<title>`, `<meta charset>`, `<meta viewport>`.
