## Flash Cards

https://roadmap.sh/projects/flash-cards

Overview:

In this project, I created a simple flashcard app using HTML, CSS, and basic JavaScript. The app includes the following features:
- Pre-defined flashcards with questions and answers.
- A progress bar to visually track the user's progress.
- The ability to view flashcards one at a time and flip them to reveal the answer.
- Simple navigation controls to cycle through the deck.
